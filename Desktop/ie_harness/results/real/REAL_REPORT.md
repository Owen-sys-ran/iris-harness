# 真实 Benchmark 上的 IE-CRSI-Harness 实验报告

> 冻结增强骨干权重，只进化外围 Harness（预处理 / 后端选择 / 后端参数 / 后处理 / TTA），SIM 按退化根因跨轮次积累成功与失败经验。本报告全部基于真实成对评测集。

## 4. SIM 闭环行为

- SIM 累计 **45** 条：improved 7，regressed 22，neutral 16；失败条目留存用于剪枝。
- Selector 依据 SIM 历史自动剪枝 **15** 个曾回退的 (编辑键, 取值) 候选。

### 判定采用归一化综合评分

`score = 0.5·ΔPSNR/10 + 0.3·ΔSSIM/0.2 − 0.2·Δ色偏/20`；硬退化保护：PSNR≤−0.3dB 或 SSIM≤−0.01 或色偏≥+3.0 直接判 regressed。避免单一 PSNR 埋没 SSIM/色偏上的改善。

## 5. 逐任务观察

- **低光**：evolved，后端 zero_dce；PSNR 14.94→18.67（+3.73），SSIM 0.653→0.702（+0.049），色偏 45.64→25.84（-19.80）；改进轴：gain, gamma。
- **去雾**：evolved，后端 aodnet；PSNR 21.08→21.07（-0.01），SSIM 0.897→0.909（+0.011），色偏 12.87→10.68（-2.20）；改进轴：channel_gain, gamma；PSNR 基本持平，但 SSIM/色偏/最差样本方差收敛，PSNR 标准差 3.40→2.04（差样本被拉回）。
- **水下**：evolved，后端 funie_gan；PSNR 19.45→20.21（+0.77），SSIM 0.752→0.803（+0.051），色偏 13.16→13.23（+0.07）；改进轴：tta_flip。
- **去噪**：baseline，后端 nlm；PSNR 24.80→24.80（+0.00），SSIM 0.647→0.647（+0.000），色偏 1.38→1.38（+0.00）；改进轴：无单因素改进。

## 6. 局限与下一步

- 深度后端为轻量老模型，部分任务上限受骨干约束；Harness 只优化外围，不更新权重。
- 去噪/去雾备选传统后端偏弱，后续可接入 RIDNet/轻量 Transformer 等更强冻结骨干做插拔对比。
- 指标未含 LPIPS / CLIP-IQA 与主观评分；候选空间仍以单因素 + 少量二阶组合为主。
- EUVP 为抽样 40 对；后续可扩到全量并补充 UIEB、SID、SOTS 等真实基准。
